# Cada línea lleva un techo de versión mayor, no solo un piso.
#
# El piso solo dice "de acá para arriba", así que `pip install -r` en la máquina
# de GitHub resuelve a lo último que se haya publicado el día que corra. Eso
# está bien mientras alguien mire la salida; en una corrida desatendida cada dos
# días significa que una versión mayor de cualquiera de estas cuatro entra sola,
# sin que nadie la haya probado, y rompe la corrida por algo que no cambiamos.
#
# El techo es por versión MAYOR y no una versión exacta a propósito: los
# arreglos de seguridad y de fallos siguen entrando solos, que es lo que uno
# quiere, y lo único que queda afuera es el cambio que rompe compatibilidad por
# definición.
#
# Los pisos son lo probado: son las versiones con las que corrieron todas las
# mediciones de spec.md §14 y las corridas reales del 01 al 07 de setiembre.
